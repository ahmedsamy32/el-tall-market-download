# سوق التل - بوابة التحميل الرسمية (eltal-market Web Portal)

موقع ويب متكامل وخفيف وسريع ومزود بلوحة تحكم تفاعلية، مبني بالكامل باستخدام **HTML5** و **Tailwind CSS** و **Vanilla JavaScript**.

---

## 🌟 مميزات المشروع

- **100% Static & Fast:** يعمل مباشرة بدون الحاجة إلى خادم PHP أو قاعدة بيانات MySQL.
- **لوحة تحكم تفاعلية (`admin.html`):** تتيح إدارة كافة بيانات وروابط التطبيق والإصدارات والبانرات مع الحفظ الفوري وإمكانية تصدير كود `data.js` وتغيير كلمة السر.
- **جاهز للنشر الفوري:** يمكن رفعه مباشرة على **GitHub Pages**, **Vercel**, **Netlify**, **Cloudflare Pages** أو أي استضافة ويب عادية.
- **تصميم عصري متجاوب:** يدعم الوضع الليلي والنهاري (Dark / Light Mode) وسلايدر إعلانات متجاوب باللمس.
- **إعدادات مركزية مرنة:** ملف `assets/js/data.js` يتيح لك تعديل أرقام الإصدارات، روابط التحميل (APK / iOS)، البانرات الإعلانية، وبيانات التواصل في مكان واحد لتتحدث تلقائياً عبر كامل الموقع.

---

## 📁 هيكلية الملفات

- `index.html` - الصفحة الرئيسية وسلايدر الإعلانات وبطاقات التحميل السريع.
- `download.html` - صفحة التحميل الرسمية مع تفاصيل النسخ وروابط التنزيل.
- `about.html` - صفحة عن التطبيق والمميزات وطرق التواصل الرسمية.
- `privacy.html` - صفحة سياسة الخصوصية وسياسة الاسترجاع والاستبدال.
- `terms.html` - صفحة الشروط والأحكام.
- `admin.html` - لوحة التحكم التفاعلية لإدارة الموقع وتعديل البيانات وحفظها.
- `market/` - تطبيق الويب (Flutter Web App).
- `assets/` - ملفات التنسيق (CSS)، الصور والأيقونات، والأكواد البرمجية (JS).

## 🔑 لوحة التحكم (Admin Panel)

* **الرابط:** افتح ملف [`admin.html`](file:///e:/FlutterProjects/%D9%85%D9%88%D9%82%D8%B9%20%D8%AA%D8%AD%D9%85%D9%8A%D9%84%20%D8%B3%D9%88%D9%82%20%D8%A7%D9%84%D8%AA%D9%84/admin.html) في المتصفح أو ادخل على `/admin` على السيرفر.
* **كلمة المرور الافتراضية:** `admin123` (يمكنك تغييرها من قسم الأمان داخل اللوحة).
* **طريقة العمل:**
  1. عدّل البيانات المرغوبة (أرقام الإصدارات، الروابط، البانرات).
  2. اضغط **"حفظ التغييرات"** للتطبيق الفوري على المتصفح.
  3. اضغط **"تنزيل ملف data.js"** واستبدل الملف داخل `assets/js/data.js` عند الرغبة في اعتماد التعديلات رسمياً على السيرفر و GitHub.
